# Career Search 360 — V2.2 logo assets

## Talentiques

`talentiques-store-wordmark.png` is a transparent 893 × 141 export of the existing white wordmark in `src/components/store/StorePageFR.tsx`: Plus Jakarta Sans, `font-black`, `tracking-tight`. It uses the existing cached font in `.next/static/media/fba5a26ea33df6a3-s.p.1bbdebe6.woff2`, rendered at 8× size. The old header uses text and has no standalone matching vector asset. No new font or package was installed. The landing header uses the local image, with no live text recreation or turquoise T.

## Companies

The company destinations and social-proof claim were supplied by the user. All images are served locally. Geometric proportions are retained; optical heights are set in `content.ts`. Original Société Générale colours are retained. The official white Deloitte wordmark is displayed in monochrome through CSS for legibility on white, with the source SVG unchanged. AGCO uses an official transparent 900px PNG; the other 12 company assets are SVG.

Exact original/download URLs and file metadata are recorded in `companies/sources.json`. Official websites were used where available. Wikimedia Commons supplies Emirates, Schneider Electric, Rolex and FedEx; Companieslogo supplies Orica when the official homepage blocks retrieval. Hermès is the unchanged `ng__hermes-logo` SVG symbol exported from its official homepage.
